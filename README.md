# project-controls-starter-toolkit

A practical PM operations toolkit designed to help early-career project professionals understand real project coordination workflows.

Built to bridge the gap between PM certifications/theory and practical project coordination workflows commonly used in PMO, infrastructure, mining, energy, and industrial project environments.

3.Who it is for

-PM students

-aspiring Project Coordinators

-Project Administrators

-PMO Support Officers

-junior PM professionals

4. What is included

-RAID logs

-action registers

-status reports

-stakeholder tools

-governance trackers

-planning templates

-PM workflow guides
